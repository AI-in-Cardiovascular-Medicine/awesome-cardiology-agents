# Awesome Cardiology Agents

A living, systematically searched atlas of large language model agents in cardiology, and the
open toolkit behind it: schemas, controlled vocabularies, appraisal checklists, human-in-the-loop
extraction and review pages, and the code to reproduce the review.

The first release will accompany our review, now in preparation. Until then this repository
holds only this notice.
